# 📊 Power BI Sales and Returns Dashboard

## 📝 Project Overview

This repository contains a comprehensive, interactive Power BI dashboard designed to analyze sales, orders, and return rates. The project provides actionable business insights through a three-page analytical report.

## 📑 Pages & Functionality

### 1. Main Page (Overview)
* **KPIs & Metrics:** Displays total revenue ($1.83M), total orders, and total return values.
* **Top Performer Highlight:** Identifies the top-selling product ("Water Bottle - 30 oz.").
* **Interactive Visualizations:**
  * **Treemap:** Illustrates sales distribution across core categories (Accessories, Bikes, Clothing).
  * **Bar Chart:** Visualizes total orders by subcategory (e.g., Tires and Tubes).
  * **Matrix:** Details product-level metrics including Total Orders and Return Rates.
* **Global Slicers:** Date range slider and region selector for dynamic filtering.

### 2. Category Details
* **Detailed Analysis:** Focuses on product category performance.
* **Matrix Table:** Breaks down the specific share (% of All Orders) across various categories in the dataset.

### 3. Product Detail
* **Target vs. Actuals:** Features Gauge Charts for comparing target vs. actual values for Sales Volume, Revenue, and Target Returns (e.g., AWC Logo Cap analysis).


## 🛠️ Technologies Used

* **Power BI Desktop** – Data modeling, DAX, and interactive visualizations.
* **Microsoft Excel** – Primary data source.

## 🚀 How to View the Dashboard
1. Download the `.pbix` file from this repository.
2. Open it with **Microsoft Power BI Desktop**.
